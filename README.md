# Architektur Atelier – Softwarearchitektur mit Spring PetClinic

Die Astro-Microsite liegt in [whole-wavelength](whole-wavelength/README.md).

Lokal: `cd whole-wavelength`, `npm ci`, `npm run dev -- --background`.

Prüfen: `npm run check`, `npm test`, `npm run build`, `npm run verify`.

Die Seite erklärt System- und Codearchitektur in 13 Lernkapiteln und einem interaktiven Architecture Explorer.

[Veröffentlichte Microsite](https://guendeti.github.io/projektarbeit-test/) · [Konzeption](docs/KONZEPT.md) · [Prüfprotokoll](docs/QUALITAET.md)
## Ergänzter Abschlussstand

Die Microsite bietet alle Lernkapitel als Markdown und zwei Java-Quellcodearchive. `petclinic-architectures` enthält den isolierten Visit-Vergleich; `petclinic-adapted` die vollständige gepinnte Spring PetClinic mit vier zusätzlichen Visit-Wegen. Änderungen und Start stehen dort in `ARCHITECTURE-CHANGES.md`. Technische Nachweise: `docs/QUALITAET.md`; Anforderungsabgleich: `docs/ANFORDERUNGEN.md`.
