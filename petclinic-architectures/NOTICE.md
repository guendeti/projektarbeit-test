# Herkunft und Nutzung

Der Code in diesem Verzeichnis ist eine eigenständige didaktische Neuimplementierung des beschriebenen Visit-Use-Cases. Es wurde kein vollständiges Spring-PetClinic-Repository übernommen. Begriffe und fachlicher Referenzablauf stammen aus der Spring PetClinic (Spring Projects, Apache License 2.0): https://github.com/spring-projects/spring-petclinic/tree/500158f732419217507c7656904b8e6aa1bcc0d6

Spring Boot, H2, JUnit und ArchUnit werden als Maven-Abhängigkeiten bezogen; deren eigene Lizenzen gelten unverändert. Für diese Lernbeispiele wird die MIT-Lizenz im beigefügten LICENSE gewährt.
